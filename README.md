# AgroVet 🐾

## Sobre o Projeto

O **AgroVet** é uma aplicação web desenvolvida como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS), utilizando tecnologias modernas de desenvolvimento Front-end e Back-end.

## Finalidade

O sistema tem como objetivo facilitar o gerenciamento de produtos, categorias, fornecedores e usuários, proporcionando uma plataforma organizada e intuitiva para administração de informações.

Além disso, conta com um painel administrativo que apresenta gráficos e indicadores para auxiliar na visualização dos dados cadastrados.

## Tecnologias Utilizadas

- **Front-end:** React, TypeScript, Vite, Axios e Recharts.
- **Back-end:** Node.js, Express e TypeScript.
- **Banco de Dados:** MySQL.
- **Ferramentas:** Git, GitHub e Docker.
